# Chatbot Buku Panduan Akademik UII

Aplikasi RAG berbasis Gradio + FAISS + Gemini API.

## File yang harus ada
- app.py
- requirements.txt
- index.faiss
- chunks.pkl
- embeddings.npy

## Environment Variable
- GOOGLE_API_KEY

## Jalankan lokal
```bash
pip install -r requirements.txt
python app.py
```
